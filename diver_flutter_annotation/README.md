# diver_flutter_annotation

Provides the `@DiverRoute(...)` annotation for attaching a human-readable **name** and **description** to a [`go_router`](https://pub.dev/packages/go_router) route, so they show up in the `diver/app_urls.json` generated by [`diver_flutter_builder`](../diver_flutter_builder).

The annotation carries no runtime behaviour — it's pure metadata that the builder reads at build time. (Its React Native / Expo counterpart is the `defineDiverRoute` helper from [`diver_expo_builder`](../diver_expo_builder)'s `/route` subpath.)

## Installation

Add it as a regular dependency (it's imported by your route files, so not a dev dependency):

```yaml
dependencies:
  diver_flutter_annotation:
    git:
      url: https://github.com/Mikkelet/diver_flutter_annotation
```

Or via a local path:

```yaml
dependencies:
  diver_flutter_annotation:
    path: ../diver_flutter_annotation
```

## Usage

Annotate a `go_router` route class alongside its `@TypedGoRoute`:

```dart
import 'package:diver_flutter_annotation/diver_flutter_annotation.dart';

@DiverRoute(name: 'Settings', description: 'App settings screen')
@TypedGoRoute<SettingsRoute>(path: '/settings')
class SettingsRoute extends GoRouteData {
  SettingsRoute({this.tab});
  final String? tab;
}
```

This contributes the `name` and `description` to that route's entry in `diver/app_urls.json` when you run `dart run build_runner build`.

| Field | Type | Default |
| --- | --- | --- |
| `name` | `String` | `""` — the builder falls back to the route URL (`host/path`) |
| `description` | `String` | `""` |

## Without the annotation

The annotation is optional. A route without `@DiverRoute` is still picked up by the builder — it just gets the URL as its `name` and an empty `description`. Add the annotation only where you want friendlier labels in Diver.

See [`diver_flutter_builder`](../diver_flutter_builder) for how routes are discovered and uploaded.
